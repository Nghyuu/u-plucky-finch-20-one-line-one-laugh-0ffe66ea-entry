One funny line, at most 200 characters — an entry for the [One Line, One Laugh](https://make.fun/bounty/u-plucky-finch-20-one-line-one-laugh-0ffe66ea) bounty on make.fun.

## How it works

`main.ts` (Node 22, stdlib only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` — exactly one line, one trailing newline, mode `0644`.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
